# AFOS fixed model adapter

This private module implements the `afos.model.v1` transport and an official DSH `LlmAdapter` for one managed model. It is source code for a restricted enterprise Profile and a server gateway, not an activated production endpoint. `FixedModelGateway` refuses execution unless trusted server configuration explicitly sets `enabled: true`; the surrounding server must separately authorize `models.stream` for the current run.

The Host registers `EnterpriseModelAdapter` with the public `ctx.llm.registerAdapter()` API. The existing DSH model loop, message assembly, cancellation, and Session events retain ownership. The adapter receives only an injected trusted `ModelTransport` and current run checks. It has no fetch endpoint, vendor credential, route discovery, retry engine, Agent loop, or MCP transport. The caller cannot choose a different provider/model. `serializeModelRequest()` and `validateModelRequest()` expose a closed JSON contract without URL, token, client usage, actor, organization, or role fields.

On the server, `FixedModelGateway` creates the public official `DeepSeekAdapter` with one frozen HTTPS Messages endpoint and one fixed model. The supplier key stays in its server closure. The official adapter translates and streams the provider wire protocol, sends its required attribution header, and refuses redirects. No global fetch interception is used in production. The gateway disables optional API extensions and does not resolve local attachments or send a raw Session identity. Supplied model messages are still intentionally sent to the approved model provider; consent and material provenance belong to the surrounding trusted Profile/Broker.

Current server ACL/run validation must return a `ModelAuthorityLease` for each check: a verified scope key, permitted tool names, expiry, and an active revocation signal. All lease signals, including refreshed signals, terminate the stable vendor signal. Checks run at admission, before private authentication and the final provider request preparation, and before each emitted chunk. Expiry and a five-minute maximum also interrupt an idle request. Tool definitions, historical tool calls, and returned tool names must be allowed; returned tools must additionally have been declared in this request. A server must drive its revocation signal when authorization changes. Sampling alone cannot immediately interrupt an idle provider connection.

`encodeModelSse()` and `decodeModelSse()` carry only the public DSH chunk vocabulary. The decoder limits each frame to 64 KiB and the stream to 16 MiB; it validates UTF-8, version, fields, counters, terminal ordering, and truncated streams. It requires an owning transport cancellation/deadline signal. Cancellation races non-cooperative reads without hanging the consumer. Provider error bodies, private causes, replay envelopes, and transport-forged error messages are removed at the boundary. A terminal success is exposed only after server usage settlement succeeds and the active signal is rechecked.

The gateway requires an atomic server `ModelUsageLedger`. A durable implementation must persist reservations and idempotent settlements, bind them to the verified account/project/run scope, and reconcile uncertain writes. Reservation is conservatively based on the configured context window plus output cap, and remains charged when usage is unknown. The configured window and actual provider accounting still need real verification; this is a token budget, not a guaranteed monetary cap. `InMemoryModelUsageLedger` is explicitly an offline fixture and cannot serve as production billing storage. A reservation that ignores cancellation and completes late is retained and reconciled without dispatching a model call; an unsettled or crashed reservation must never be silently cleared by the mounted server.

The pinned official adapter initializes absent provider counters to zero. This module accepts its aggregate counts as known only when both input and output counters are positive; a missing or zero counter remains `unknown`, no synthetic usage chunk is emitted, and its reservation is retained. This deliberately treats valid zero-count edge cases conservatively. Cost is always `unknown` because no verified provider prices were supplied. Client-reported usage cannot enter this contract or the server ledger. Ledger outcomes describe the server-observed model transport, not a business approval, artifact receipt, or proof that the supplier stopped generation after a disconnected request.

P1 here supports bounded text and non-deferred tools only. Images, file references, developer tool-history extensions, custom content blocks, and caller reasoning-effort overrides are refused with `UNSUPPORTED_MODEL_CONTENT`; they are not translated into arbitrary local paths or a fallback endpoint. Image/file acceptance remains `NOT_RUN`. The formal D10 cases AT-34, AT-45, AT-46, and AT-47 remain `NOT_RUN` until the mounted Profile, current real NocoBase authority, durable ledger, authorized gateway credentials, and full material-to-draft chain are tested. Offline fixtures do not close those cases.

Run `COREPACK_HOME=/workspace/afos-handoff/corepack corepack pnpm install --frozen-lockfile`, `corepack pnpm run typecheck`, and `corepack pnpm test` from this directory. The package pins DSH `0.1.7-rc.2` and the current WorkDSH Cordis `4.0.3`. Published DSH peers request Cordis `~4.0.4`; real public LLM registry composition is tested on the current `4.0.3` lock, but cross-runtime exchange and a dependency upgrade are not claimed. See `REUSE.md` and `evidence/delivery.json` for measured provenance, command evidence, review scope, and rollback.

To roll back this isolated source addition before activation, remove only this module through a reviewed local patch/revert. After mounting a gateway, disable the explicit model action first; preserve unknown reservations and provider usage records while restoring the former code. Do not delete credentials, Session files, artifacts, or NocoBase records as a code rollback. No source push, server deployment, external model call, production migration, or permission expansion was performed by this task.
