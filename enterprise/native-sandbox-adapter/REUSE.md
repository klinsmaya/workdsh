# D06 official capability reuse record

Task: D06. Owner: `/root/afos_native_implementation`. Source worktree: `afos/native-boundary`, based on `64ec37478b9311baacb6530a5055b5aa1e9941a8`. This module is not loaded by any Profile.

The public DSH `@deepseek-ai/dsh-subprocess@0.1.7-rc.2` interface supplies `SubprocessSpawnSpec`, `SubprocessHandle`, `spawn`, `terminate`, `waitForExit`, and bounded collected output. The adapter consumes these interfaces rather than implementing another process runner, Agent loop, shell tool, MCP transport, or approval engine. The published package types are checked by this module's build. Reference: [official subprocess documentation](https://github.com/deepseek-ai/deepseek-harness/blob/477b4f420553e8a52c2fbccc464d7561b239c443/docs/subsystems/subprocess.md).

The official DSH sandbox provider describes file effects, with `full`/`partial` completeness; it explicitly does not promise network or process visibility isolation. It cannot alone satisfy AFOS full-path isolation. We do not replace the official provider or allow an escalation to `danger-full-access`. Reference: [public sandbox seam](https://github.com/deepseek-ai/deepseek-harness/blob/477b4f420553e8a52c2fbccc464d7561b239c443/packages/sandbox/sandbox/src/index.ts).

SRT research ref `117eb928202b53c80d3cb6527d88d1b90e4ca7a9` declares version `0.0.78`. The adapter pins that npm version; the npm artifact's provenance is recorded separately, without claiming its git tree equals the research tree. Only public exports are consumed: `SandboxManager`, `SandboxRuntimeConfigSchema`, and configuration types. Public `initialize`, `checkDependenciesAsync`, `wrapWithSandboxArgv`, `reset` are used. Reference: [SRT public exports](https://github.com/anthropics/sandbox-runtime/blob/117eb928202b53c80d3cb6527d88d1b90e4ca7a9/src/index.ts), [manager API](https://github.com/anthropics/sandbox-runtime/blob/117eb928202b53c80d3cb6527d88d1b90e4ca7a9/src/sandbox/sandbox-manager.ts).

SRT's manager has module-global mutable configuration. Each prepared invocation owns a separate Worker with a copied minimal environment, fixed configuration, and reset after the DSH managed range is empty. The adapter never calls global `updateConfig`; it does not share manager state across runs. Worker messages are private adapter lifecycle IPC, not a new model tool or execution protocol.

AFOS differences: immutable run roots; read deny-by-default; only isolated workspace/tmp writable; a fixed environment; no tool-supplied path, environment, network, or shell executable; fail-closed capability/coverage gates; no privileged installation. Direct Host file, PTC, browser, model HTTP and desktop IPC are not confined by this process adapter and cannot be claimed enabled with it alone.
