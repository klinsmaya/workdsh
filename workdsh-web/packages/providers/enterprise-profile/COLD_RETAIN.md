This adapter requests exactly one `next()` and awaits `return()` in `finally` before forwarding the unchanged actual opening snapshot. The pinned original iterator promotes a prepared Agent after its first yield, even before checking abort; cancellation never substitutes for `return()`.

Only ordinary safe Session IDs, the original assistant snapshot option, and bounded original page windows are accepted. Unknown fields, caller cursors, subagents, unowned IDs and invalid bounds reject. Captured controller/query identity, absence of public ingress, cold absence of live Agent/Session, Main epoch/signal, authority expiry and physical proof are checked before and after asynchronous work. Original source disposal errors reject the snapshot. Pending first reads receive the actual query signal and close the real observation and listeners.

After the original iterator closes, the adapter holds the actual snapshot while periodically rechecking the existing Main read grant before its short deadline. Grants must retain the same epoch and signal. This introduces no second source read, event accumulator, history loop or execution. Single-session denial ends only its logical read. A cancelled pending renewal ends that already-closed logical source, while the original Gateway owns carrier retry. Consumer release, account/project/Host/window cutoff and physical expiry end the held snapshot; a reconnect acquires a new grant and original snapshot.

Denial, replacement, cancellation or expiry aborts the original query and awaits iterator return; no Agent or source is recreated.
