# Optional original Client native view after a business task

`bootEnterpriseNativeWsCore` is an explicit D08/D09 engineering composition. It requires a private Main `nativeCaller.assertRequest` capability returning a live AbortSignal and a finite expiry no more than 60 seconds ahead. Missing capabilities refuse boot. The default Core, default desktop activation, P1/G3 and D13/D14 remain unchanged and unpassed.

Official DSH 0.1.7-rc.2 Loader Groups retain the private Controller/Reader assembly. A third Group contains the original Gateway and Typert registry and the five-read business facade. Its WebServer capability delegates only the original `/api/remote.mux` upgrade registration to the same parent physical WebServer. It creates no listener, port, mux, codec or execution engine. The Connection capability delegates the original browser admission, operator and fetch APIs; its `/api` interceptor contribution is deliberately zero. The original parent fixed Ingress remains the only RPC owner. This restricted capability is not a general Connection implementation.

Every physical native upgrade first passes the original Connection Host/Origin/signed-cookie check, then the independent private Main caller proof, then a fresh owned Session read grant. Proof validation waits at most ten seconds. Caller, Host and Session revocation and the earliest proof/read expiry close the actual socket. A paused upgrade with no buffered bytes observes FIN through Node's public zero-byte read; buffered early bytes can defer cleanup until the bounded proof deadline. The wrapper never consumes or reframes carrier bytes.

The Root HTTP proof module protects the three canonical native read paths before fresh Main. It remains independent of the optional mux owner. In WS mode the ReadBridge requires that owner to be present, and refuses if it has been unloaded. Standard AsyncLocalStorage carries one private HTTP caller lease through the existing Ingress; the inner read lease combines its signal and earliest expiry and checks them before returning original encoded values. Trusted in-process SharedFetch capabilities remain private and bypass physical caller authentication.

ADR AFOS-0006: one authenticated operator, more restrictive per-socket scopes. The original admitted PeerId is retained. An official lifecycle-owned child Context under that original Peer holds only the bounded private caller metadata. A readonly PeerScope view passes through the unchanged original Gateway. WeakMaps key the request and this exact view object, never the shared operator id. The view's disposer removes only its own child fiber and socket grant, never the original operator. It neither creates another principal nor increases permissions. The facade reads the public `this.ctx.invocation.peer` and checks its exact caller grant after awaits and before every native stream frame. Direct original-operator invocations have no such grant and refuse. No socket event listeners are patched and no private transport implementation is imported.

Only the original five Session definitions are available; the other fourteen Session methods, generic SRC services and `$events/result` refuse. The original empty remote-event source lets the original Gateway produce its readiness frame with `home: ''`. It emits no Host business notifications, Session content or waterfalls. Each method still obtains fresh Main account/project/Recovery ownership and performs the original inner Agent/Session/expiry checks. Official Agent, Session, persistence, Remote and Client remain the execution and protocol owners.

This candidate supports native view after a successfully started live business task. Before any such Session exists, the real original WS upgrade refuses. This proves a bounded component path; it does not prove a complete ModuleLoader/Workspace/Conversation GUI bootstrap.
