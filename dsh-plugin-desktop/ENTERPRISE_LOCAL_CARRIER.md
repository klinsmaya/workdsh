# Existing Electron window: local enterprise draft face

This D02/D05/D09 slice keeps one WorkDSH Electron window owner. EnterpriseMainSession owns account selection and credentials; EnterpriseRecoveryStore owns durable local drafts. The release-owned original published frontend, ModuleSystem, Loader, layout and Slots mount the existing enterprise draft panel through its alternative local-client export. No replacement shell, Conversation, Remote, protocol or Agent loop is introduced.

The window uses contextIsolation, sandbox:true and nodeIntegration:false. A fixed preload exposes only state(), edit({draftId,content}) and a payload-free invalidation subscription to the exact afos-local://drafts/index.html top frame. Two Main handlers independently check the actual WebContents, current mainFrame, exact document and the current account/project lifetime on every call and after asynchronous projection. Main-frame navigation/reload aborts the old document lifetime before a new document can request state; window close aborts outstanding projections and removes its handlers. The unique public stateless draftView supplies the existing DTO. No token, private capability, raw record, path, URL or arbitrary IPC argument reaches the Renderer. Logout/project change immediately invalidates the client model and unsaved editor; a confirmed Host stop preserves same-account local work. Main stop remains the owner of execution interruption.

The local scheme serves only canonical GET assets in a release manifest, with exact regular-file size/SHA-256 checks. API, file, upload, WebSocket and unknown routes are refused. Connect, frames, objects and forms remain forbidden; popup, navigation, redirect, webview and downloads are denied. This face cannot read materials, start/cancel a task, call a model or archive. Execution capabilities remain ingressValidated:false/sandbox:unavailable. Missing managed resources do not create configuration or grant permission.

## Original frontend CSP compatibility decision

The real Electron consumer initially produced an empty page: the unchanged official frontend index-Q6zc2uHV.js creates its Cordis expression evaluator with new Function at module initialization. The first strict script-src self policy rejected it with an actual EvalError. Replacing the official frontend or copying its private implementation is outside this slice.

The explicit local-only decision allows script-src self unsafe-eval, while script-src-elem remains self without inline scripts. Only hashed release scripts are loaded. The official embedded data font is allowed by font-src self data. Connect-src remains none. This permits the original evaluator; it must never evaluate project names, draft bodies or IPC data. Those use the existing strict DTO parser and React text rendering. Malicious expression-shaped and Markdown/HTML text, foreign documents/frames/windows, unlisted assets, external connections and extra IPC payloads require real consumer negative evidence. Online Connection and native admission policies are unchanged. This compatibility policy is not evidence of production OS isolation.

## Release and evidence limits

The host resource paths come from app.getAppPath()/resourcesPath, not personal runtime environment overrides. A separately managed afos-host-runtime.json, if supplied, contains only the strict afos.host-runtime.v1 release/policy and fixed model identifier/limits. It is excluded from the public package files and is not automatically generated. Existing Main/Broker/server model policy remains authoritative. The existing EnterpriseCliHost is the sole optional process owner; real exit/disconnect notification occurs once only after readiness, never for intentional stop or failed startup.

Linux Electron 43.3.0 may run the component consumer only with an explicitly documented --no-sandbox fixture in this container. BrowserWindow sandbox:true is preserved; the OS sandbox attempt is separately blocked. Windows/macOS, signing, packaged/portable target consumers, actual enterprise identity and production native issuer/online UI require separate evidence. Original AT-03/04/05/06/31/40/41/42/43/44/48/49/50/51/52 and P1G3 are not promoted by fixtures; D13-D15 remain unstarted. The original shell may still display native session controls, whose original Connection has no route in this local face. Full online UI, trusted port publication and private Main issuer integration are separate engineering work; the local asset scheme cannot bypass the original loopback Origin check.

Rollback: preserve all user changes, Recovery/outbox and vault data. Stop the optional Host, revert only the reviewed carrier/local-client source patch in an isolated branch, rebuild the previous carrier and repeat its consumers. No data migration, external write, release or permission expansion is part of this slice.
